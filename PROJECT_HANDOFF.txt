SCIENTIFIC IDEA
---------------
"Gotham Loops" is a framework for bounded novelty:

  maximize or study heterogeneity / novelty
  subject to preserving a salient structural relationship.

The first implemented statistical formulation uses a balanced one-way ANOVA ICC as the structural criterion.

The current deterministic question is:

  Given grouped data already observed, how far can the next observation in each group move in a specified direction while the updated data remain exactly on a chosen ICC threshold?

This turns a scalar threshold into a geometry of admissible observations and, under repeated updating, into a constrained dynamical system.

The current work has moved beyond a single static frontier. The main scientific result is now that repeated threshold-hugging updates admit exact low-dimensional recurrences and explicit control rules.


CURRENT MATHEMATICAL MODEL
--------------------------
Current scope:
  - G balanced groups
  - common current group size n
  - one proposed new observation per group
  - one-way ANOVA / random-intercept ICC
  - centered proposal deviations for the current frontier and sequence theory
  - threshold-hugging sequences use a target ICC tau

For group g:

  current group mean:
    ybar_g

  grand mean:
    ybar

  group offset:
    a_g = ybar_g - ybar

Let:

  a = vector of group offsets
  A = ||a||^2 = group_offset_ss
  W = SS_within

A proposed observation is:

  x_g = ybar_g + d_g

For centered proposals:

  mean(d_g) = 0

Define:

  r = ||d||

and alignment:

  c = (a' d) / (||a|| ||d||)

with:

  c = -1  directly opposing current group separation
  c =  0  orthogonal to current group-offset vector
  c = +1  directly reinforcing current group separation

The balanced one-way ANOVA ICC is:

  ICC = (MS_between - MS_within) /
        (MS_between + (n - 1) * MS_within)

Negative ICC estimates are retained rather than truncated.


EXACT UPDATE IDENTITIES
-----------------------
After adding one centered proposal observation per group:

  W' = W + n/(n+1) * r^2

  B' = (n+1) A + 2 sqrt(A) r c + r^2/(n+1)

The updated group-offset sum of squares is:

  A' = A + 2 sqrt(A) r c/(n+1) + r^2/(n+1)^2

This immediately implies that c = 0 is NOT exactly structurally neutral at finite n whenever r > 0, because the quadratic term remains positive.


IMPLEMENTED PACKAGE FUNCTIONS
-----------------------------
Current package functions:

1. anova_icc(data, outcome, group)
   - balanced one-way ANOVA ICC
   - validates inputs and rejects unbalanced data in this first formulation

2. gotham_state(data, outcome, group)
   - returns n_groups, group_size, grand_mean, group_means, group_offsets,
     group_offset_ss, ss_between, ss_within, ms_between, ms_within, icc

3. gotham_update(state, deviations)
   - exact analytic update after one proposed observation per group
   - records proposal geometry

4. gotham_frontier(state, threshold, alignment, ...)
   - analytic centered frontier in radius/alignment coordinates
   - general implementation still permits 0, 1, or 2 finite nonnegative crossings

5. gotham_profile(state, radius, alignment, mean_deviation = 0, ...)
   - deterministic representative microstate for a requested macrostate (r, c)

6. gotham_profile_set(...)
   - representative profiles at threshold + epsilon, threshold, threshold - epsilon

7. gotham_band(...)
   - maps an ICC epsilon band into observation-space radial distances

8. gotham_sequence(state, steps, threshold, alignment, ...)
   - sequentially follows the first frontier crossing and updates the state
   - accepts fixed or step-specific alignment values

Important interpretation:
  gotham_sequence() follows the FIRST frontier crossing. In the threshold-hugging regime studied below, H2 proves that there is exactly one positive crossing once its sufficient condition holds. The more general gotham_frontier() should remain capable of representing other topologies.

HYPOTHESIS / RESULT REGISTRY

The research notebook now contains H1-H9.

H1. ZERO-RADIUS HEADROOM IS PATH-INVARIANT
------------------------------------------
Status:
  exact identity derived and numerically verified

If the current balanced state has common group size n and current ICC rho, adding one observation exactly at each current group mean gives:

  rho_0(n, rho)
    = [n^2 rho + n rho - 2 rho + 2] /
      [n^2 + n rho - rho + 1]

Headroom:

  rho_0 - rho
    = (1-rho)(n rho - rho + 2) /
      [n^2 + n rho - rho + 1]

For 0 <= rho < 1 this is positive.

For fixed 0 < rho < 1:

  rho_0 - rho = rho(1-rho)/n + O(n^-2)

Numerical verification across the 450 sequence-grid diagnostics:

  max absolute discrepancy = 3.330669e-16

Key consequence:
  conditional on current group size and current ICC, zero-radius headroom is independent of alignment history, absolute scale, and G.


H2. UNIQUE POSITIVE FRONTIER CROSSING IN THE THRESHOLD REGIME
-------------------------------------------------------------
Status:
  exact sufficient condition derived and numerically verified

For centered proposals the large-radius ICC limit is:

  rho_infinity(n, G) = 1 / [G + n(G-1)]

If:

  rho_0 > tau > rho_infinity

then the quadratic frontier equation has exactly one positive root for every c in [-1, 1].

For a state already on the threshold, H1 guarantees rho_0 > tau, so the condition reduces to:

  tau > 1 / [G + n(G-1)]

Because the right side decreases with n, once this condition holds in a threshold-hugging sequence it continues to hold at every later step.

Therefore the current canonical sequence cannot suddenly develop two-root/re-entry behavior later.

A second corollary is that, for a fixed state in this regime, the positive frontier radius is strictly increasing in alignment c.

Numerical verification over all 450 diagnostics:

  infinity formula max error = 0
  all sufficient inequalities satisfied = TRUE
  all cases exactly one finite positive root = TRUE


H3. ORTHOGONALITY IS NOT STRUCTURAL NEUTRALITY
----------------------------------------------
Status:

At c = 0:

  A' = A + r^2/(n+1)^2 > A

for r > 0.

Thus orthogonal proposals eliminate the linear cross-product term but not the positive quadratic contribution.

H6. SCALE-FREE NORMALIZED RECURRENCE
------------------------------------
Status:
  exact recurrence derived and numerically verified

Once the current state is exactly on ICC threshold tau:

  W_n / A_n
    = n G (n-1)(1-tau) /
      [(G-1){1 + (n-1)tau}]

Define normalized frontier radius:

  z_n = r_n / sqrt(A_n)

Then:

  -a_n z_n^2 + 2 c z_n + gamma_n = 0

where:

  a_n
    = [tau{G + n(G-1)} - 1] /
      [G(n+1)(1-tau)]

  gamma_n
    = [tau(n-1) + 2] /
      [tau(n-1) + 1]

Under H2, the unique positive solution is:

  z_n(c)
    = [c + sqrt(c^2 + a_n gamma_n)] / a_n

Thus r_n/sqrt(A_n) depends only on:

  n, G, tau, c

and NOT on:

  absolute scale of A_n
  detailed path/history that produced the threshold state

The exact multiplicative recurrence is:

  A_{n+1}
    = A_n [1 + 2 c z_n(c)/(n+1) + z_n(c)^2/(n+1)^2]

Numerical verification:

  normalized-radius max error = 7.771561e-15
  A recurrence max relative error = 5.461076e-16
  different-history normalized-radius spread = 4.440892e-16

Asymptotically:

  a_n -> a_infinity
      = tau(G-1) / [G(1-tau)]

  z_n(c) -> z_infinity(c)

with:

  z_infinity(c)
    = [c + sqrt(c^2 + a_infinity)] / a_infinity

For fixed c != 0:

  A_n asymptotically scales as n^[2 c z_infinity(c)]
  r_n asymptotically scales as n^[c z_infinity(c)]

Therefore:

  c < 0  => A_n -> 0 and r_n -> 0
  c = 0  => A_n and r_n approach finite positive limits
  c > 0  => A_n -> infinity and r_n -> infinity


H7. MEAN-ZERO VARIABLE ALIGNMENT IS NOT GOTHAM-NEUTRAL
------------------------------------------------------
Status:
  exact cumulative-drift criterion derived and numerically verified

For variable alignment c_n, define:

  h(c) = 2 c z_infinity(c)

Then:

  log A_N
    = log A_start + sum_n h(c_n)/n + O(1)

Thus long-run behavior depends on a harmonic-time accumulation of a NONLINEAR drift, not the ordinary mean of the alignments.

For symmetric +/- c:

  h(c) + h(-c)
    = 4 c^2 / a_infinity > 0

So equal-frequency alternating +c and -c schedules have mean alignment zero but positive asymptotic Gotham drift.

Canonical predicted A exponents for symmetric alternation:

  +/- 0.25  -> 0.046875
  +/- 0.50  -> 0.187500
  +/- 1.00  -> 0.750000

In 5,000-step recurrence runs, estimated late-time slopes closely matched these predictions.

For +/- 1, the final A ratio was approximately:

  143.135659

Direct variable-alignment recurrence versus gotham_sequence():

  max relative discrepancy = 6.808267e-16

Key conceptual result:

  mean alignment = 0
  does NOT imply
  structural neutrality


H8. GOTHAM-NEUTRAL MIXED POLICIES REQUIRE ASYMMETRIC WEIGHTING
--------------------------------------------------------------
Status:
  exact asymptotic weighting rule and finite-n log-neutral policy derived and verified

For two available alignments:

  c_- < 0 < c_+

asymptotic neutrality requires nonlinear drift balance:

  p_+ h(c_+) + (1-p_+) h(c_-) = 0

so:

  p_+*
    = -h(c_-) / [h(c_+) - h(c_-)]

For symmetric +/- c:

  p_+*
    = 1/2 - c/[2 sqrt(c^2 + a_infinity)]

  p_-*
    = 1/2 + c/[2 sqrt(c^2 + a_infinity)]

Thus a neutral policy requires MORE opposing than reinforcing moves.

Canonical G = 3, tau = 0.80 neutral shares:

  magnitude   positive share   negative share
  ---------   --------------   --------------
    0.25        0.424335         0.575665
    0.50        0.353615         0.646385
    1.00        0.238884         0.761116

Exact finite-n log-neutral stochastic share:

  p_n^+
    = -log m_n(c_-) /
      [log m_n(c_+) - log m_n(c_-)]

For symmetric +/- 0.5 this converges toward 0.353615 as n increases.

A deterministic greedy controller using exact multipliers was also tested for 5,000 steps. Final A ratios stayed essentially at 1:

  magnitude 0.25 -> 0.999966
  magnitude 0.50 -> 1.000080
  magnitude 1.00 -> 0.999868

For the +/- 0.5 controller, recurrence versus gotham_sequence():

  max relative discrepancy = 3.346695e-15

Important distinction:
  directional balance, asymptotic structural balance, finite-n log balance, and deterministic finite-horizon balance are not equivalent notions.


H9. EXACT ONE-STEP STRUCTURALLY NEUTRAL ALIGNMENT
-------------------------------------------------
Status:
  exact formula derived and directly verified against gotham_sequence()

Exact one-step structural neutrality requires:

  A_{n+1} = A_n

Using H6, this implies:

  z_n* = -2 c_n* (n+1)

so the exact neutral direction is slightly opposing:

  c_n* < 0

Closed form:

  c_n*
    = -1/2 * sqrt(
        G(1-tau){tau(n-1)+2} /
        [(n+1)(G-1)(1+n tau){tau(n-1)+1}]
      )

Associated normalized radius:

  z_n*
    = sqrt(
        G(1-tau)(n+1){tau(n-1)+2} /
        [(G-1)(1+n tau){tau(n-1)+1}]
      )

Asymptotically:

  c_n*
    = -z_infinity(0)/(2n) + O(n^-2)

and:

  z_n* -> z_infinity(0)

For G = 3, tau = 0.80:

  n = 4      c_n* = -0.06798418
  n = 10     c_n* = -0.02915413
  n = 50     c_n* = -0.00606302
  n = 100    c_n* = -0.00304662
  n = 1000   c_n* = -0.00030603

A direct 200-step gotham_sequence() run used the step-specific c_n* values.

Verification:

    6.661338e-16

    2.697842e-14

Thus H9 is fully verified at numerical tolerance.

Interpretation:

CURRENT SCIENTIFIC TAKEAWAY
---------------------------
The original empirical finding was that the same ICC threshold permits radically different observation-space heterogeneity depending on alignment.

The stronger result now is that the deterministic centered threshold-hugging model has an unexpectedly clean analytic structure:

  1. zero-radius headroom is path-invariant conditional on n and current ICC;
  2. the threshold regime has exactly one positive centered frontier crossing under a simple persistent condition;
  3. threshold-state dynamics collapse to a scale-free normalized recurrence;
  4. fixed alignment yields explicit contraction / finite-limit / expansion regimes;
  5. mean-zero directional balance is not structural balance;
  6. neutral mixed policies require asymmetric directional weighting;
  7. exact finite-n single-step neutrality is available in closed form and is slightly opposing.

The deterministic centered ICC version is therefore now much closer to a small constrained dynamical/control system than to a brute-force simulation exercise.


IMPORTANT TERMINOLOGY / INTERPRETATION CAUTIONS
-----------------------------------------------
1. ICC is the first structural criterion, not claimed to be universally correct.

2. The current model is balanced and one-way.

3. Current frontier/sequence theory is for centered proposals.

4. "Alignment" is relative to the CURRENT group-offset vector, not a fixed original direction in observation coordinates.

5. gotham_profile() returns one representative microstate; many actual observation vectors share the same radius/alignment macrostate.

6. The general gotham_frontier() should continue to permit 0/1/2 crossings. H2 is a result for the more specific threshold-hugging centered regime.

7. The illustrative tau = 0.80 and epsilon = 0.02 are not universal substantive standards.

8. H5 should now be described as a finite-horizon/transient comparison, not as evidence for two different asymptotic critical alignments.

9. H7/H8 neutrality is governed by nonlinear/harmonic-time drift, not simply raw average alignment.

10. H8 mixed-policy neutrality and H9 single-step deterministic neutrality are different control strategies.
